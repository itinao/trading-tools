## 1. 背景と目的

M1 は株価をモックで通した。M2（ニュース・開示・スコア）と M4（スクリーニング）に進むには、日本株の **株価・指標・過去の日足・ニュース・適時開示・決算数値** の取得元を決める必要がある。候補を実際に叩き、取得可否・鮮度・利用条件を記録して採用を決める。

## 2. 検証結果（2026-09-20、キー不要の3候補）

### 2.1 Yahoo Finance（非公式パッケージ `yahoo-finance2` v4）

| 項目 | 結果 |
| --- | --- |
| 現在値・前日終値 | 取れる。`7203.T` 形式。`regularMarketTime` は直近の引け（15:30 JST） |
| 過去の日足 | 1 年分（257 本）を 1 リクエストで取れる。`drawdown_60d` / `below_ma200` の履歴を初日から満たせる |
| 指標 | PER（実績・予想）、PBR、配当利回り、時価総額、ROE、営業利益率、増収率、D/E、次回決算日 |
| 複数銘柄 | `quote([...])` で一括取得できる |
| 速度 | 4 リクエストで 1 秒未満 |
| 条件 | 非公式（Yahoo の内部 API を利用）。個人利用・低頻度なら実用上問題ないが、**仕様変更で止まり得る**（0001 R2）。レート制限は明示されていないため、保有 + ウォッチの数十銘柄を日次 1 回に留める |

### 2.2 Google News RSS

| 項目 | 結果 |
| --- | --- |
| 取得 | `https://news.google.com/rss/search?q=<銘柄名>&hl=ja&gl=JP&ceid=JP:ja` で 100 件、0.1 秒 |
| 内容 | 見出し、公開日時、リンク（Google 経由の URL）、媒体名は見出し末尾の ` - 日本経済新聞` で分かる。本文は無い |
| 精度 | 銘柄名で検索するため、同名の製品・スポーツ等のノイズが混ざる（トヨタで 5 件中 2 件がクルマの話題）。証券コードを足しても件数は変わらず、精度は上がらない |
| 条件 | 非公式・規約上はグレー。個人利用・日次 1 回 / 銘柄に留める |

### 2.3 TDnet（適時開示情報閲覧サービス）

| 項目 | 結果 |
| --- | --- |
| 取得 | 日付ごとの一覧ページ `I_list_<ページ>_<YYYYMMDD>.html`（100 件 / ページ、1 日 200〜300 件、3 ページ）。UTF-8 |
| 内容 | 時刻、証券コード（5 桁 = 4 桁 + `0`）、会社名、表題、PDF リンク、XBRL の有無 |
| 絞り込み | 一覧を全件取って保有銘柄のコードで絞る。1 日 3 リクエスト |
| 表題での判別 | 「決算短信」「業績予想の修正」「配当（予定）」は表題で分かる。**上方 / 下方の向きは表題に無い**ことが多く、PDF 本文（または XBRL）を読む必要がある |
| 保持期間 | 約 1 か月分。日次で取り込めば十分 |
| 条件 | 公式・無料。API は無くページ構造に依存（0001 R2 と同じ扱い） |

### 2.4 Yahoo Finance の財務諸表（四半期・年次）— 追加検証

`fundamentalsTimeSeries` で売上・営業利益・純利益・総資産・自己資本・営業 CF・EPS が取れる。営業利益率と自己資本比率が計算できる。保有 27 銘柄でのカバー率:

| データ | 取れる銘柄 |
| --- | --- |
| 四半期 5 期以上（前年同期比が出せる） | 2 / 27 |
| 年次 2 年以上（前年比が出せる） | 24 / 27 |
| どちらも無し | 3 / 27 |

四半期は大型株しか無く実用にならない。年次は 4 年分が 9 割の銘柄で取れる。`quoteSummary` の財務諸表モジュールは 2024 年 11 月以降ほぼ空で、`fundamentalsTimeSeries` を使う必要がある。

### 2.5 J-Quants API（JPX 公式、未検証: アカウントが必要）

公開情報より（[料金・プラン](https://jpx-jquants.com/ja/spec/data-spec)）:

| プラン | 月額 | 遅延 | 期間 |
| --- | --- | --- | --- |
| Free | 0 円 | **12 週遅れ** | 直近 2 年 |
| Light | 1,650 円 | なし | 2 年 |
| Standard | 3,300 円 | なし | 5 年 |

- 株価、財務諸表（四半期の売上・利益・自己資本など）、業績予想、決算発表予定日が取れる。ファンダ系シグナル（0001 付録 A の `margin_deterioration` / `equity_ratio_drop` / `growth_streak`）に最も適した公式ソース
- Free は 12 週遅れなので **検知には使えない**（スクリーニングの母集団や過去分析には使える）
- 最新値が必要なら Light 以上の契約が要る

### 2.6 EDINET API

有価証券報告書・四半期報告書。API キーの登録が必要。決算短信より遅い（提出まで 45 日）ため、日次の検知には向かない。M2 では使わない。

## 3. 決定

| 種類 | 採用 | 理由 |
| --- | --- | --- |
| 株価・前日終値・過去の日足 | **Yahoo Finance** | 無料・即日・1 年分の日足が一括で取れる。モック Provider を差し替える |
| 指標（PER / PBR / 配当利回り / ROE / 営業利益率 / D/E） | **Yahoo Finance** | 同上。`fundamentals` として日次スナップショットに保存し、M2 のスコアと M4 のスクリーニングに使う |
| ニュース | **Google News RSS** | 無料・即時。ノイズは AI 判定（M2 の `assess`）で落とす |
| 適時開示 | **TDnet** | 公式・無料。表題で種別を判別し、向きが必要なものは PDF 本文を AI に読ませる（M2 で設計） |
| 決算の数値（時系列） | **Yahoo Finance の年次（4 年分）** | 四半期は 27 銘柄中 2 銘柄しか取れず実用にならない。年次なら 9 割で取れる。ファンダ系シグナルは年次の前年比で作る |
| 四半期の変化 | **TDnet の決算短信 + AI が PDF を読む** | 四半期の数値時系列は無料では取れない。決算短信は表題で検知でき、内容は AI に読ませる（M2 で設計） |
| J-Quants | **契約しない**（将来の選択肢） | 利用者の判断。Provider 抽象を保ち、必要になったら追加する |

### Provider の構成（0003 §3.3 の拡張）

| Provider | 提供するもの |
| --- | --- |
| `yahoo` | `fetchQuotes`（現在値・前日終値）、`fetchHistory`（日足）、`fetchFundamentals`（指標）、`fetchFinancials`（年次の財務諸表） |
| `google-news` | `fetchNews`（見出し・日時・URL・媒体） |
| `tdnet` | `fetchDisclosures`（日付の一覧から保有銘柄分） |
| `mock` | 既存。テストと手元の検証用に残す |

Provider の切り替えは環境変数 `TRADING_QUOTE_PROVIDER`（既定を `yahoo` に変更）。

## 4. リスク

| # | 内容 | 対応 |
| --- | --- | --- |
| R1 | Yahoo / Google News は非公式で、仕様変更や遮断で止まる | 取得失敗を `failed` に記録し、ダッシュボードの「株価が古い」バナーで気づける（0001 R2）。止まったら J-Quants Light に切り替えられるよう Provider 抽象を保つ |
| R2 | 銘柄名でのニュース検索はノイズが多い | AI 判定で「銘柄に関係ない」を1つの判定結果として持つ |
| R3 | TDnet の開示の向き（上方 / 下方）が表題で分からない | PDF 本文の抽出を M2 で検証する。難しければ XBRL の業績予想サマリーを読む |

## 決定事項（壁打ちの結果）

| 論点 | 決定 |
| --- | --- |
| 無料の非公式ソース（Yahoo / Google News） | 使う。止まるリスクは「株価が古い」バナーと Provider 抽象で受ける |
| J-Quants Light | 契約しない |
| 決算の時系列 | Yahoo の年次（4 年分）で代替。ファンダ系シグナルは年次の前年比。四半期の変化は TDnet の決算短信を AI が読む |
